feature: **Companion window chrome**: shell and manifest windows accept `floating`, `transparent`, and `click_through` (macOS AppKit host) — the desktop-companion shape: an always-on-top, non-rectangular window whose pixels composite straight over the desktop, follows the user across Spaces and full-screen apps, and supports optional full click-through.
- **`fx.moveWindow(label, dx, dy, clamp)`**: synchronous window movement by screen-space delta with visible-frame clamping; the result reports the applied origin, clamp hits, live primary-button state, host-tracked drag velocity, the one-shot drag-release edge, and the global cursor — enough to drive an app-owned drag loop with release momentum without observing OS events (macOS AppKit host; results are not yet journaled for session replay).
- **`fx.resizeWindow(label, width, height, anchor)`**: exact window sizing in screen points with a fixed anchor (`top_left` or `bottom_center`), so a companion window fits itself to its drawn content instead of reserving an invisible click-eating band (macOS AppKit host).
- **`fx.focusWindow(label)`**: raises a window by label and activates the app — the "bring my window back" verb for commands that should surface an already-open window.
